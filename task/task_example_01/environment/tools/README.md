# Scientific software available in the shared image

The installed [FourPhonon solver](fourphonon.md) computes mode-resolved third- and fourth-order scattering and RTA transport from the supplied BAs force constants. NumPy and SciPy are available for analysis. `check_software.py` checks imports and the FourPhonon and MPI executables. The input files are an existing force model; no force-constant fitting is required.
