# Agent environment

`Dockerfile` defines the software image shared by the agent and the human baseline. `requirements.txt` lists direct scientific packages; `requirements.lock` freezes transitive versions for CPython 3.11 on Linux x86-64. `data/nims/` contains eight original source archives and a catalog. `tools/` contains executable data and software inspection utilities. `skills/` contains unmodified, publicly sourced Agent Skills with their license. The image installs phonopy, phono3py, spglib, symfc, seekpath, pypolymlp, ASE, hiPhive, pymatgen, NumPy, SciPy, SymPy, pandas, and matplotlib. `solution/`, `tests/`, and `authoring/` are excluded from the image.
