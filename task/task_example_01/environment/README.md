# Agent environment

`Dockerfile` defines the agent-visible software stack. `requirements.txt` lists direct scientific packages; `requirements.lock` freezes their transitive versions for CPython 3.11 on Linux x86-64. Regenerate the lock with `uv pip compile requirements.txt --python-platform x86_64-unknown-linux-gnu --python-version 3.11 --output-file requirements.lock` and rerun CI before changing it. `data/nims/` contains eight source archives and an agent-visible catalog; `tools/` contains optional inspection, symmetry, and interaction diagnostics; `skills/` explains methods, limits, and the output interface. All data are available at task start. The agent can choose among symmetry analysis, force-constant reconstruction, scattering calculations, transport comparisons, and literature synthesis. `solution/`, `tests/`, and `authoring/` are excluded from this image.
