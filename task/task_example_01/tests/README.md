# Objective verifier

`Dockerfile` isolates `verify.py` from the agent image and disables runtime network access. `test.sh` captures a natural final answer from Harbor's agent logs without requiring a filename or JSON schema. Such an answer receives `pending_scientific_review` in `/logs/verifier/assessment.json` and no automatic passing reward: length or citations alone do not establish scientific correctness. If a report and evidence index are present, the verifier additionally checks source-consistent 300 K conductivity values, space groups, and evidence links for two same-composition polymorph comparisons. This yields an **objective evidence score only**; it cannot certify the mechanism, causal interpretation, literature synthesis, or scientific quality. Those require `authoring/rubric.yaml` and domain review.
