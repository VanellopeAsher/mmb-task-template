# Objective verifier

`Dockerfile` isolates `verify.py` from the agent image and disables runtime network access. `test.sh` accepts a natural final answer from Harbor's agent logs, without a required filename or JSON schema. It checks only answer length and traceable evidence pointers in that mode. If a report and evidence index are present, it additionally verifies source-consistent 300 K conductivity values, space groups, and evidence links for two same-composition polymorph comparisons. It writes 0 or 1 to `/logs/verifier/reward.txt`. This is an **objective completeness score only**; it cannot certify the mechanism, causal interpretation, literature synthesis, or scientific quality. Those require `authoring/rubric.yaml` and domain review.
