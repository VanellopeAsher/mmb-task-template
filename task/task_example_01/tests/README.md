# Objective verifier

`Dockerfile` isolates `verify.py` from the agent image and disables runtime network access. `test.sh` captures a natural final answer from Harbor's agent logs without requiring a filename or JSON schema. If a report and evidence index are present, the verifier checks selected source-log values and record structure. These checks can be satisfied by an incorrect mechanism claim, so both structured and natural answers receive reward `0` with scientific correctness pending. A passing scientific reward requires a narrower problem with an independently established target and a matching correctness test. The current example is a task-authoring and data-feasibility prototype, not an automatically gradable benchmark item.
