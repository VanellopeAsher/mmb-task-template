# Original scientific brief

## Problem

声子散射选择规则何时足以预测主导散射机制？

## Research area

规律发现 · 晶体对称性 · 非谐散射

## Scientific context

对称性及能量—动量约束可以抑制部分散射通道，但散射相空间缩小不必导致总散射同步减弱。需要同时考虑非谐耦合矩阵元和高阶过程，确定由声子谱推断热输运的适用范围。

## Suggested computational entry point

从晶格动力学提取选择规则与散射相空间，再显式计算三、四声子散射率；比较规则预判、模式寿命和热导率之间的一致性。

This is an authoring suggestion, not an Agent instruction or required sequence.

## Literature basis

文献将声子散射选择规则定位为筛选工具，并讨论三声子过程被抑制后四声子散射的重要性及该框架的局限。

Ravichandran, [*Tuning thermal transport using phonon scattering selection rules*](https://www.nature.com/articles/s44435-026-00018-1), *npj Thermal Science and Engineering* (2026).
