# Restricted screw-axis check and evidence boundary

For a one-dimensional mode representation along an n_p screw-invariant wave-vector line, let the screw eigenvalue convention be λ_m(q_z) = exp[2πi(m−p q_z)/n], where q_z is in reciprocal-lattice units. A 1+2→3 cubic matrix element transforms as λ_1 λ_2 λ_3*. Its invariance requires m_1+m_2−m_3−p(q_1+q_2−q_3) ≡ 0 mod n. Crystal-momentum conservation sets q_1+q_2−q_3=G_z, an integer. For 6_3, Δm ≡ 3G_z mod 6. This gives a nontrivial distinction between Normal G_z=0 and odd-axial-Umklapp G_z=1 events.

Phono3py represents a three-phonon triplet in the all-incoming convention, q_1+q_2+q_3=G_z. The equivalent condition used by `probe_interactions.py` is m_1+m_2+m_3−pG_z ≡ 0 mod n. The outgoing mode in the first convention is the complex conjugate of the corresponding incoming mode in the second.

This is a *necessary* rule for modes with well-defined screw eigenvalues on the invariant line. Degenerate subspaces must first be resolved into a screw eigenbasis. Its scope is the identified modes and wave vectors. Generic wave vectors, additional operations, energy conservation, and the magnitude of surviving anharmonic couplings all matter. The scalar condition is checked by `feasibility/witness/screw_selection.py`; `feasibility/witness/probe_interactions.py` assigns actual GaN mode labels using [phonopy's position-phase convention](https://phonopy.github.io/phonopy/symmetry-adapted-modes.html). The 2022 [nonsymmorphic phonon pseudoangular-momentum paper](https://doi.org/10.1103/PhysRevResearch.4.L012024) supports wave-vector-dependent screw labels, while [Yang et al. (2021)](https://doi.org/10.1103/PhysRevB.103.184302) supplies a general symmetry-based anharmonic-scattering framework with symmorphic examples. The [2026 perspective](https://doi.org/10.1038/s44435-026-00018-1) explicitly treats full three-dimensional nonsymmorphic generalization as an open direction.

The NIMS source logs establish computed conductivity differences among polymorphs. They do **not** directly report which three-phonon matrix elements are zero because of the screw operation, nor do they isolate symmetry from structural and anharmonic changes. The reference report therefore presents the transport comparison as a boundary on simple universal claims. `gan_interaction_probe.json` reconstructs cubic IFCs, assigns screw labels to GaN phonons after diagonalizing degenerate subspaces, and compares the resulting forbidden/allowed classification with computed matrix elements for sampled Normal and odd-axial-Umklapp triplets. In the latter, the allowed label sum shifts by 3, directly testing the fractional translation in the restricted rule. All predicted forbidden elements are numerically below the declared relative threshold. This verifies selected model couplings, not the importance of those channels to bulk thermal transport. Converged energy-conserving scattering and a controlled symmetry-breaking perturbation would be needed for a causal conductivity conclusion.

`aln_interaction_probe.json` independently repeats the same mode-resolved test for AlN wurtzite, with the same allowed/forbidden pattern on the sampled grid. This supports transfer of the restricted 6_3 character condition across two force models; it does not establish a general conductivity trend.

`zns_interaction_probe.json` gives the same restricted selection pattern for ZnS wurtzite, while the source transport log puts ZnS wurtzite below zincblende in conductivity. Together the three mode probes and the polymorph comparisons separate the repeatable symmetry constraint from a non-universal transport response.
