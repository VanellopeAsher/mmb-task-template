# Restricted screw-axis check and evidence boundary

For a one-dimensional mode representation along an n_p screw-invariant wave-vector line, let the screw eigenvalue convention be λ_m(q_z) = exp[2πi(m−p q_z)/n], where q_z is in reciprocal-lattice units. A 1+2→3 cubic matrix element transforms as λ_1 λ_2 λ_3*. Its invariance requires m_1+m_2−m_3−p(q_1+q_2−q_3) ≡ 0 mod n. Crystal-momentum conservation sets q_1+q_2−q_3=G_z, an integer. For 6_3, Δm ≡ 3G_z mod 6. This gives a nontrivial distinction between Normal G_z=0 and odd-axial-Umklapp G_z=1 events.

This is a *necessary* rule for nondegenerate modes with well-defined screw eigenvalues on the invariant line. It is not a general result for every phonon in every nonsymmorphic crystal. Degenerate representations, generic wave vectors, additional operations, energy conservation, and the magnitude of surviving anharmonic couplings all matter. The scalar condition is checked by `environment/tools/screw_selection.py`; the tool does not assign actual material mode labels. The 2022 [nonsymmorphic phonon pseudoangular-momentum paper](https://doi.org/10.1103/PhysRevResearch.4.L012024) supports wave-vector-dependent screw labels, while [Yang et al. (2021)](https://doi.org/10.1103/PhysRevB.103.184302) supplies a general symmetry-based anharmonic-scattering framework with symmorphic examples. The [2026 perspective](https://doi.org/10.1038/s44435-026-00018-1) explicitly treats full three-dimensional nonsymmorphic generalization as an open direction.

The NIMS source logs establish computed conductivity differences among polymorphs. They do **not** directly report which three-phonon matrix elements are zero because of the screw operation, nor do they isolate symmetry from structural and anharmonic changes. The reference report therefore presents the transport comparison as a boundary on simple universal claims. The added `gan_interaction_probe.json` reconstructs cubic IFCs and finds a contrast in near-zero matrix-element counts for sampled axial and off-axis triplets. It does not classify formal selection rules: a stronger material-specific result still needs actual little-group mode representations, allowed/forbidden comparisons within symmetry-invariant subspaces, and converged transport calculations under a controlled symmetry-breaking perturbation.
