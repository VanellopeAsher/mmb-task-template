# Independent evidence

This author-only directory records reasoning and validation boundaries. `selection_rule.md` derives a restricted screw-axis condition and separates it from unsupported transport claims. `check_verifier.py` tests that the Oracle artifacts pass while altered numerical evidence and a missing report fail. The source-log numbers used by the objective verifier were cross-checked against the eight original ZIP archives. Do not mount this directory into the agent environment.

`gan_interaction_probe.json` is a reproducible, exploratory mode-triplet diagnostic generated by `environment/tools/probe_interactions.py` from the supplied `gan_wurtzite_mp804.zip` displacement and `FORCES_FC3` data using phono3py 4.10.0, phonopy 4.10.0, spglib 2.8.0, and symfc 1.8.0. The mesh is 3×3×6; q1 is (0,0,1/6). For each non-Gamma triplet, the script counts squared interaction strengths below 10^-8 of that triplet's maximum. Two all-axis triplets have 1062/1728 and 1056/1728 near-zero entries; the six off-axis triplets have 256–418/1728. This is a coarse-grid numerical pattern, not a count of formally forbidden processes. Degenerate-mode basis choices, other symmetries, kinematics, and fitting errors can change the counts. Assigning the actual screw representations, testing invariant subspaces, and controlling symmetry-breaking changes remain necessary before attributing bulk conductivity to a screw selection rule.
