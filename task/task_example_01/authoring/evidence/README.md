# Independent evidence

This author-only directory records reasoning and validation boundaries. `selection_rule.md` derives a restricted screw-axis condition and separates it from unsupported transport claims. `check_verifier.py` tests that a valid fixture passes while altered numerical evidence and a missing report fail, and checks extraction of a natural answer from an ATIF trajectory. The source-log numbers used by the objective verifier were cross-checked against the eight original ZIP archives. Do not mount this directory into the agent environment.

`gan_interaction_probe.json` is generated by `feasibility/witness/probe_interactions.py` from the supplied `gan_wurtzite_mp804.zip` displacement and `FORCES_FC3` data using phono3py 4.10.0, phonopy 4.10.0, spglib 2.8.0, and symfc 1.8.0. On a 3×3×6 mesh, the raw interaction strengths in the software's arbitrary degenerate-mode basis give 1062/1728 and 1056/1728 near-zero entries for two non-Gamma, all-axis triplets, versus 256–418/1728 for six off-axis triplets. These raw counts are basis dependent.

The script then obtains GaN's 6_3 operation from its structure, diagonalizes it within degenerate phonon subspaces, and recomputes interaction strengths. For each of five sampled non-Gamma axial triplets, 1440/1728 mode combinations fail the screw-character condition and all 1440 have squared coupling below 10^-8 of the triplet maximum; none of the 288 allowed combinations falls below the threshold. One triplet has three q_z=1/3 modes and axial reciprocal vector G_z=1. Its allowed label sum shifts from 0 to 3 modulo 6; a rotation-only rule would misclassify 288 near-zero combinations as allowed. The mode-assignment residual and each triplet's maximum forbidden strength are stored in the JSON. This directly checks a restricted material-specific selection condition in a symmetrized force model. It does not show that these channels contribute appreciably to thermal resistance; energy conservation, mesh convergence, force-model uncertainty, and a controlled symmetry-breaking comparison remain open.

`aln_interaction_probe.json` repeats the same calculation on the separate AlN wurtzite source archive. All five sampled axial triplets again have 1440/1440 predicted forbidden combinations below the numerical threshold and 0/288 allowed combinations below it; the mode-assignment residual is below 3×10^-14. This is an independent material check of the restricted mode rule, while leaving the bulk transport effect unresolved.

`zns_interaction_probe.json` repeats the calculation on the ZnS wurtzite source archive, which has 24 phonon modes per q-point. In each of five sampled axial triplets, all 11,520 predicted forbidden combinations fall below the numerical threshold, while none of the 2,304 predicted allowed combinations does; the mode-assignment residual is below 10^-12. The ZnS wurtzite conductivity is lower than its zincblende counterpart in the supplied transport logs, illustrating that observed screw selection rules do not determine a universal bulk-conductivity ranking.
