# Independent evidence

This author-only directory stores the original interaction probe outputs for GaN, AlN, and ZnS, a restricted screw-rule derivation in `selection_rule.md`, a scoring-dependency review in `shortcut_audit.md`, and two quality checks. `check_verifier.py` confirms the oracle answer passes while old formula/transport shortcuts, perturbed coupling values, and missing artifacts fail. `check_witness.py` recomputes the scored values from the source force archives in the pinned scientific image and compares the mode-classification counts with the saved probes. Neither script is mounted into the evaluated Agent's environment.

The saved `*_interaction_probe.json` files were produced by `solution/witness/probe_interactions.py` using phono3py 4.10.0, phonopy 4.10.0, spglib 2.8.0, and symfc 1.8.0 on a `3 × 3 × 6` mesh. For the selected axial triplets, forbidden combinations are numerically near zero while allowed combinations carry model-specific strengths. The scored largest-sector shares, effective sector counts, and odd-to-normal strength ratios require those strengths and screw-mode labels. The raw force models, mesh, and chosen processes define the scope of the numbers.
