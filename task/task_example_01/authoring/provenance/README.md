# Provenance

`fetch_nims.py` downloaded eight original NIMS `phonondb_LTC` ZIP archives and verified each ZIP member's CRC. `nims_manifest.json` records the source page, archive member list, byte size, and SHA-256 for every archive. It also generated the agent-visible `environment/data/nims/catalog.json` with source links and checksums. Each of the eight individual NIMS dataset pages states CC BY 4.0; credit Atsushi Togo and NIMS and link the corresponding dataset page when reusing the data.

The source index is https://github.com/atztogo/phonondb/blob/main/mdr/phonondb_LTC/README.md. The data are PBEsol/MLP-based calculations, not an experimental thermal-conductivity survey. The source archives include the displacement/force data needed to reconstruct second- and third-order force constants, but the supplied transport `LTC-calc.log` is a published calculation with its own settings. Keep the source ZIPs unchanged; any extracted or transformed files should be documented with a script and checksum.
