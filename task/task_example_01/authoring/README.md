# Private authoring materials

This author-only directory is never mounted into the agent image. `rubric.yaml` records the numerical scoring contract; `provenance/` contains the source acquisition script and checksums; `evidence/` records the scientific cross-checks; `human_baseline/` documents the five-expert protocol and a clearly simulated example panel. No actual expert baseline has been collected. The public worked example reveals these materials and must be packaged with a hidden solution and verifier for live evaluation.
