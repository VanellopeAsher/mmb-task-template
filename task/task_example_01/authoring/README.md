# Private authoring materials

This author-only directory is never mounted into the agent image. `scientific_brief.md` preserves the original research problem and its context. `rubric.yaml` records the numerical scoring contract of the current engineering pilot; `provenance/` contains the source acquisition script and checksums; `evidence/fc4_gap.md` records the missing fourth-order data; `human_baseline/` documents the five-expert protocol and a clearly simulated example panel. No actual expert baseline has been collected. The public worked example reveals these materials and must be packaged with a hidden solution and verifier for live evaluation.
