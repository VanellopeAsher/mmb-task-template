# Private authoring materials

This author-only directory is never mounted into the agent image. `rubric.yaml` defines scientific-quality criteria; `provenance/` contains the source acquisition script and checksums; `evidence/` records independent reasoning and validation boundaries; `human_baseline/` records the expert protocol and, when collected, actual attempts. Scientific review is separate from the objective verifier. The public worked example reveals these materials and is not suitable as a hidden benchmark item without repackaging.
