# Private authoring materials

This author-only directory is never mounted into the agent image. `rubric.yaml` defines scientific-quality criteria; `provenance/` contains the source acquisition script and checksums; `evidence/` records independent reasoning and validation boundaries; `human_baseline/` documents the five-expert protocol and a clearly simulated example panel. No actual expert baseline has been collected. Scientific review is separate from the objective verifier. The public worked example reveals these materials and is not suitable as a hidden benchmark item without repackaging.
