# Human baseline

Status: **simulated example only; no real expert attempt collected**. `simulated_five_experts.json` shows five distinct hypothetical attempts under one task, environment, and time limit. Its `simulated_human_hard` value demonstrates the decision rule only; `empirical_human_hard` remains unknown. No simulated action, score, or outcome is an observed expert measurement. The Oracle and verifier are author-side feasibility checks, not human attempts.

For a real baseline, recruit exactly five independent domain experts. Give each the same `environment/` snapshot and the `metadata.human_baseline.time_limit_hours` in `task.toml`, without access to `solution/`, `tests/`, or `authoring/`. Record anonymized IDs, expertise, start/end time, environment image digest, visible materials, experiments, submitted artifacts, adjudication against the rubric, and protocol deviations. An expert may use any available route. If any one expert solves the problem within the limit, mark human-solvable. Mark human-hard only when all five valid attempts fail. Obtain permission before publishing identifiable contributions. Real task status remains unverified until these attempts occur.

Protocol inspiration: [Anthropic's BioMysteryBench human baselining](https://www.anthropic.com/research/Evaluating-Claude-For-Bioinformatics-With-BioMysteryBench), which uses up to five domain experts and calls a question human-solvable when any one answers it correctly. MMB fixes the panel size at five for a human-hard designation and reads the shared time limit from `task.toml`.
