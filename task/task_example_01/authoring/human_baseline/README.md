# Human baseline

Status: **not yet collected**. Do not treat the scripted Oracle or its local verifier pass as an expert baseline.

Recruit at most five independent domain experts. Give each person the same agent-visible environment and the same eight-hour limit, without access to `solution/`, `tests/`, or `authoring/`. Record an anonymized expert ID, relevant expertise, start/end time, environment/image digest, materials available, commands and submitted artifacts, scientific-quality rubric scores, objective-verifier outcome, and any protocol deviations. Obtain permission before publishing identifiable contributions. Until real attempts are recorded, the expert-solvability and human-difficulty requirements are unverified.
