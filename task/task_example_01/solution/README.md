# Reference solution

`answer.json` is the correct set of data-dependent interaction observables in the format published in `problem.md`. Harbor runs `solve.sh`, which writes it to `/workspace/results/answer.json`. `check_sources.sh` verifies source archives and calls `signal_check.py` in the pinned scientific image. `witness/probe_interactions.py` reconstructs the scored sector-strength measurements from the original force data; `witness/screw_selection.py` and `witness/solve.py` retain the underlying derivation and extended investigation. CI executes `authoring/evidence/check_witness.py` to recompute the answer values. This directory is withheld from the evaluated Agent and human baseline.
