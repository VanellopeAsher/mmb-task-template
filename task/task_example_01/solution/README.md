# Expert reference material

`solve.sh` runs `solve.py`, which reads the original NIMS archives and constructs one bounded reference investigation in `/workspace/results/`. It derives 100, 300, 600, and 900 K conductivity comparisons from source logs, reconstructs GaN three-phonon interaction strengths, and explains a restricted screw-axis selection condition with explicit limits. The interaction calculation can also be reproduced with `environment/tools/probe_interactions.py`; its author-side snapshot is `authoring/evidence/gan_interaction_probe.json`. This Oracle demonstrates a defensible answer, not a unique conclusion or a completed causal proof. The directory is withheld from the evaluated agent.
