# Expert reference material

`solve.sh` runs `solve.py`, which reads the original NIMS archives and constructs one bounded reference investigation in `/workspace/results/`. It derives 100, 300, 600, and 900 K conductivity comparisons from source logs, reconstructs GaN, AlN, and ZnS wurtzite three-phonon interaction strengths, assigns screw-mode labels, and checks a restricted Normal/Umklapp selection condition with explicit limits. The interaction calculations can also be reproduced individually with `solution/probe_interactions.py`; author-side snapshots are in `authoring/evidence/`. This Oracle demonstrates a defensible answer, not a unique conclusion or a completed causal transport proof. The directory is withheld from the evaluated agent.
