# UiO-66 缺陷摘要能预测周期连通吗？

这批匿名 UiO-66 模型中，缺了什么？哪些空缺呈现晶胞尺度的重复组织？仅凭空缺摘要，能否判断剩余骨架有几维周期连通？如果还能沿三个独立方向贯通，这一结论能覆盖全部剩余金属簇吗？

`/workspace/data/reference.cif` 是完整参考。十三个 `structures/sample_*.cif` 是由参考结构删除构件得到的未弛豫几何模型，无补偿端基。观测窗口是边长 62.1012 Å 的立方体，相当于 3×3×3 个常规晶胞。每个完整常规晶胞有 4 个 Zr₆ 簇和 24 个 BDC。统计以原窗口为单位。完整 BDC 的八碳骨架连接最近的两个不同 Zr₆ 簇（中心距各不超过 8 Å）。孤立的剩余金属簇也属于模型。可用 Zr–Zr < 4.5 Å 和 C–C < 1.8 Å 的周期最短像识别构件，参考位点和平移匹配的距离容差为 0.25 Å。

在 `/workspace/results/answer.json` 提交 `samples` 和 `counterexample`。可选 `analysis` 不计客观分。

## 各样本的诊断

`samples` 以全部样本 ID 为键。每个样本包括：

- `defect_type` 为 `missing_cluster` 或 `missing_linker`。有缺簇时报告缺簇，连带移除的配体不另计；否则报告缺配体。
- `missing_site_count` 是相应的空缺数，缺簇和缺配体的分母分别为 108 和 648。
- `spatial` 描述沿三个常规晶轴各平移 20.7004 Å 时的空缺图案重复。可填 `{"full_repeat_axes": 2}` 这样的完整重合轴数（0–3），也可填 `{"overlap_counts": [0, 36, 36]}` 这样的三个重合位点数，顺序不限。完整重合表明在所测平移下存在精确重复。其它组织形式与独立随机删除的相容性需要额外证据。
- `connectivity` 包含 `method` 和 `components`。用 `winding_rank` 时，`components` 为各分量的周期秩（0–3）。周期秩指沿完整配体的闭合路径所产生的晶胞整数平移向量的张成空间维数。用 `axis_spans` 时，`components` 为各分量的 `[x, y, z]` 布尔值，分别指相应轴方向是否在该空间内。仅当这些轴能确定各分量的实际维数时，可采用后者。分量顺序不限，包含孤立簇。
- `network_status` 为 `single_3d_network`、`partial_3d_network` 或 `no_3d_network`，分别表示所有剩余簇构成单个三维周期分量、存在三维分量但它未覆盖所有剩余簇、以及没有三维分量。

## 对摘要预测的检验

`counterexample` 包含 `samples`（两个不同样本的 ID，顺序不限）和 `agreement`。选择最大分量周期秩不同的两个模型。按下列由弱到强的摘要等级，寻找本批模型所能提供的最严格反例。提交达到最高可行等级的任意一对，以及该等级的名字：

1. `concentration`：缺陷类型和空缺数相同。
2. `nearest_pairs`：另有相同最近邻空缺对数。最近邻为对应理想位点的最短非零距离 ±0.05 Å 壳层，按周期最短像，每对计一次。
3. `mean_repeat`：另有相同三轴平均空缺重合率，即三个重合位点数的总和除以三倍空缺数。
4. `axis_profile`：另有相同三轴重合位点数的多重集，允许轴置换。

结构诊断适用于这些几何模型。它提供占位、所测平移下的组织与周期连通证据。实验结构、化学稳定性及完整晶体网身份需要其它数据。
