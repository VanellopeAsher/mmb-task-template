# Tools

- `inspect_structures.py`: reads the downloaded CIFs with pymatgen, reports formula, cell volume, atom counts, and basic coordination environment summaries.
- pymatgen/ASE: CIF parsing and periodic structure analysis.
- networkx: useful for reconstructing Zr-node/linker connectivity and identifying network-level defect topology.
- The task does not prescribe a single graph-construction method; cross-check atom-count and connectivity evidence.
