# Geometric UiO-66 inputs

`reference.cif` is an ideal conventional UiO-66 cell. Thirteen `structures/sample_*.cif` are unrelaxed geometric deletion models in identical 3×3×3 observation cells. BDCs have intact eight-carbon skeletons. Missing-cluster models also remove the incident linkers. No new compensating end groups are added; isolated surviving Zr₆ clusters remain part of the model. These inputs support geometric occupancy, spatial statistics and periodic graph analysis, not claims about stable chemical termination, thermal conductivity or measured experimental structures.

Reference upstream: https://github.com/WilmerLab/mofun/tree/0e61d20a5e115220390637fc863d54dc2cddd5fb/tests/uio66 . MIT notice retained in LICENSE-MOFUN.txt. Original CIF cites Cavka et al., JACS 130, 13850–13851 (2008), with a RASPA/David Dubbeldam creation record. This provenance identifies the pristine reference only and supplies no sample-to-defect mapping.

Scientific motivation: Islamov et al., *Chemical Science* 14, 6592–6600 (2023), DOI 10.1039/d2sc06120a. These files are not that article's original simulated structures. Reference site denominators, statistical sampling window, graph definitions and output tolerances are specified in problem.md.
