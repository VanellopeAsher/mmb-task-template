# Validation notes

The nominal concentration labels and topology names came from the upstream source repository's file organization. The task bootstrap hides those labels by renaming files. `solution/witness/structure_metrics.py` now checks Zr6 connectivity under periodic boundaries and counts the Zr6 cluster deficit and carbon-site deficit directly from all nine anonymous CIFs. The three random missing-linker structures have 7/648, 65/648 and 130/648 inferred missing linkers (1.080%, 10.031%, 20.062%); the three random missing-cluster structures have 1/108, 11/108 and 22/108 missing Zr6 clusters (0.926%, 10.185%, 20.370%). The correlated structures have three, three and four intact Zr6 clusters in their unit cells. These measurements support defect family and nominal fraction, but do not identify reo/scu/bcu topology or independently establish random versus correlated spatial arrangement. The latter still requires graph-topology analysis, and public use still requires an explicit licence or permission for the upstream structures.
