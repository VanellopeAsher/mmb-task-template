# Validation notes

The nominal concentration labels and topology names came from the upstream source repository's file organization. The task bootstrap hides those labels by renaming files. `solution/witness/structure_metrics.py` checks Zr6 connectivity under periodic boundaries, groups carbon atoms into complete eight-carbon linkers and one-carbon caps, and builds a Zr6-linker multigraph from all nine anonymous CIFs. The three random missing-linker structures have 7/648, 65/648 and 130/648 missing full linkers (1.080%, 10.031%, 20.062%); the three random missing-cluster structures have 1/108, 11/108 and 22/108 missing Zr6 clusters (0.926%, 10.185%, 20.370%). The correlated structures yield distinct quotient-graph signatures: three nodes with a triangle of fourfold edges (reo), three nodes with a two-edge path of fourfold edges (scu), and four nodes with a four-edge cycle of fourfold edges (bcu). These graph signatures support the three labels within this supplied candidate set. Full periodic-net equivalence and quantitative spatial-correlation classification are not yet independently checked. Public use still requires an explicit licence or permission for the upstream structures.
