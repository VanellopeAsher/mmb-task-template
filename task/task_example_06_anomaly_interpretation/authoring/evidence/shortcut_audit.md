# Shortcut audit

The multi-stage build renames all source CIFs to opaque IDs and leaves the source-to-sample mapping out of the final Agent image. The task configuration disables Agent runtime network access. The numeric output includes measured defect fraction, complete-linker count, and cluster degree statistics for every sample, so a list of source labels cannot earn full reward. The witness reconstructs these quantities and the correlated quotient-graph signatures from CIF atom sites. A second independent parser and full periodic-net check remain release gates.
