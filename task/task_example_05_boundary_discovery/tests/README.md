# Isolated objective verification

`test.sh` reads only the submitted answer and writes reward 0 or 1. Missing or malformed submissions fail. `python tests/test_adversarial.py` exercises positive, scientific-error, boundary, malformed and shortcut cases. Targets are generated by the independent author-side calculation, not copied from the Oracle.

The verifier also writes `assessment.json` next to `reward.txt`. Sections record which checks passed and why others failed. The official reward remains binary.
