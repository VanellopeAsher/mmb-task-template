# Scientific software

Installed and tested interfaces: NumPy, SciPy, pandas, Matplotlib, statsmodels, PyMuPDF, pdfplumber and headless OpenCV; versions in requirements.txt. See the individual documentation files. `python /workspace/tools/smoke_test.py` checks imports and basic operations. WebPlotDigitizer is an optional external GUI, not installed and not needed for the supplied numerical data.
