# Human baseline protocol

No real expert attempts or independent Agent trials were performed in this revision. Recruit exactly five independent domain experts, all seeing the same problem.md, environment snapshot, tools, resources and eight-hour limit in task.toml. At least one completed solution establishes human-solvable; only all five failing permits human-hard under this protocol. Do not report either label from Oracle runs or simulated records. attempt_template.csv is a blank recording form, not evidence of participation.
