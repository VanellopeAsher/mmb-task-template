# Shortcut audit

A single-property ranking is insufficient. The verifier checks five simultaneous constraints and all six reported process quantities against source-backed rounding intervals. The five-row KPI table and `_eval.json` rows are author-only. `package_agent_traces.py` publishes the ten underlying cycle trajectories with anonymous candidate IDs, so direct filtering of a ready-made KPI table is no longer available in the Agent environment. The Agent still receives finished process trajectories for only five selected candidates. Before release as an inverse-design discovery task, the candidate space and Agent-controlled process exploration need to be expanded and checked against an executable process model; deriving balances from five existing runs alone is insufficient for the intended research difficulty.
