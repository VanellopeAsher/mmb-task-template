# Validation notes

The five-candidate table is transcribed from the cited paper's Table 1. The reference selection is NIRPAI under the explicit constraints in problem.md. The Zenodo PrISMa isotherm archive and process-simulation archive have been downloaded and matched against the published MD5 values. They contain 1,888 isotherm JSON files and 4,642 process-simulation JSON files respectively. The five Table 1 materials are **not** in the PrISMa process archive; their actual source is the separate 6.7 GB CoRE MOF process archive in the same Zenodo record.

`recompute_kpis.py` reconstructs the four methane process KPIs from the full desorption trajectory and cycle mass balance, then compares them with the separate `_eval.json` files. Of 652 equimolar `dft_jax` evaluations, 642 are fully converged and match to within 1e-6 in the reported units; 10 are excluded for nonconverged desorption or cooling steps. This establishes an independently checkable source for process reference values.

`inspect_core_archive.py` reads selected members through validated HTTP byte ranges, and `recompute_five_table.py` independently reconstructs all six published Table 1 quantities for all five materials from ten process trajectories. Each selected member passes the ZIP CRC check; the unrounded values also agree with separate source `_eval.json` files within 1e-6. The full 6.7 GB archive was not downloaded for a whole-file MD5 check. At x_CH4 = 0.003, one NIRPAI desorption step has negative signed flow; retaining signed flow reproduces the source evaluator and the published enrichment of 1.87. The 20 selected trace/evaluation members are cached in `solution/witness/reference_process_traces.zip` under the source dataset's CC-BY-4.0 license. `solution/solve.sh` now computes the answer from those trajectories.

The source `_eval.json` rows and published five-row table remain author-only. `package_agent_traces.py` strips those evaluations, replaces source material IDs with five opaque candidate IDs, and gives the Agent ten cycle trajectories. The resulting `process_trajectories.zip` has 10 members, is 1,164,878 bytes and has SHA-256 `e496fac2e0df99940eef87fea45f353817453cae35560934888d94cc3a84725c`. Its members pass ZIP CRC; no source material ID or `_eval.json` occurs in the archive. The Oracle and adversarial verifier tests pass, and GitHub Actions Docker/Harbor run [43154271828](https://github.com/VanellopeAsher/mmb-task-template/actions/runs/43154271828) passed at commit `48cd8c2`.
