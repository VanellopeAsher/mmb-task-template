# Validation notes

The five-candidate table is transcribed from the cited paper's Table 1. The reference selection is NIRPAI under the explicit constraints in problem.md. The Zenodo PrISMa isotherm archive and process-simulation archive have been downloaded and matched against the published MD5 values. They contain 1,888 isotherm JSON files and 4,642 process-simulation JSON files respectively.

`recompute_kpis.py` reconstructs the four methane process KPIs from the full desorption trajectory and cycle mass balance, then compares them with the separate `_eval.json` files. Of 652 equimolar `dft_jax` evaluations, 642 are fully converged and match to within 1e-6 in the reported units; 10 are excluded for nonconverged desorption or cooling steps. This establishes an independently checkable source for process reference values.

The process archive contains ready-made KPIs, so it must remain author-only. The public pure-component PrISMa isotherms cover 874 materials at 298.15 K, but many do not reach the low-pressure Henry regime and higher-temperature coverage is incomplete. A small baseline using pure-isotherm features and static material metadata missed the two truly feasible held-out candidates under the existing four process thresholds. These inputs alone do not justify tight process-KPI tolerances for an Agent. The task still needs an executable, validated process model or a redesigned, identifiable target before replacing the five-row lookup example.
