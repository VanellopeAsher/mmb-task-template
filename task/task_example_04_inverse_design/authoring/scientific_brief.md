# Scientific brief

## Original candidate
第一份《关键性能目标与核心科学问题》中的 MOF 混合气体分离目标：同时考虑混合物选择性、工作容量与再生能耗。

## Task interpretation
采用甲烷/氮气 TSA 分离作为具体案例，把“设计适用的多孔框架材料”转化为过程层面的多目标候选发现。材料不能只在吸附量或选择性上突出，还必须同时满足纯度、回收率、工作容量、热能需求和稀进料 enrichment 约束。

## Evidence basis
Granderath et al., Molecular Systems Design & Engineering 2026, DOI 10.1039/D6ME00066E; Zenodo dataset DOI 10.5281/zenodo.21132903. The source paper reports five MOFs with promising performance across methane feed fractions. The compact input table reproduces the reported Table 1 values.
