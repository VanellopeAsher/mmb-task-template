# Input data

`candidate_performance.csv` is a source-extracted subset of Table 1 in Granderath et al., *Fast process-level screening of metal-organic frameworks for adsorption separation using 3D classical density functional theory*, Molecular Systems Design & Engineering (2026), DOI: 10.1039/D6ME00066E.

The paper evaluates methane/nitrogen temperature-swing adsorption using process-level purity, recovery, working capacity, and thermal energy demand. The associated Zenodo dataset (DOI: 10.5281/zenodo.21132903, CC-BY-4.0) provides the broader isotherm and process-screening results. This compact task subset contains the five published cross-feed candidates and is sufficient to reproduce the stated constrained selection.
