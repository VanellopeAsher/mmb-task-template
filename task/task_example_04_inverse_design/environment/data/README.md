# Input data

`process_trajectories.zip` contains ten source-derived TSA cycle trajectories: five anonymous MOF candidates at methane feed fractions 0.5 and 0.003. The archive omits the published `_eval.json` rows and the original material IDs. Each JSON trajectory contains gas compositions, cycle step balances, heating, and adsorbent mass. The source-to-anonymous mapping stays in author-only evidence.

The trajectories come from the CoRE MOF process archive associated with Granderath et al., *Fast process-level screening of metal-organic frameworks for adsorption separation using 3D classical density functional theory*, Molecular Systems Design & Engineering (2026), DOI: 10.1039/D6ME00066E. The associated [Zenodo dataset](https://zenodo.org/records/21132903) is CC-BY-4.0. The author-side package script verifies the selected source members by ZIP CRC and produces this anonymous subset.
