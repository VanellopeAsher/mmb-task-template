# 解题资料使用边界：离线评测

## 允许使用

- 本题 problem.md、/workspace/ACCESS_POLICY.md，以及 /workspace/data、/workspace/tools、/workspace/skills 内提供的文件。
- 模型已有的通用领域知识、环境已经安装的软件及其本地帮助文档。
- 根据上述信息自行编写程序、计算、作图、拟合和检验不同解释；工作文件和最终产物写入 /workspace/results。

## 不允许使用

- 浏览器、网页搜索、外部数据库查询、外部 API、其他联网助手，以及运行期间下载的论文、原始完整数据、软件或代码。本轮为全离线评测，不另设通用联网搜索例外。
- 本题的公开解答、源论文中直接给出的本题目标结果、参考提交、完整保留轨迹或保留终点。不得通过材料身份、文件元数据或数据来源反查这些答案。
- solution/、tests/、authoring/、initial_submit/、其他版本草案、Git 历史、作者完整压缩包，或当前解题环境之外的主机文件与共享目录。
- Docker socket、主机网络、外部存储挂载或其他绕过隔离的访问方式。

若意外发现不应公开的参考答案或保留数据，请停止使用这些内容，记录位置，由组织者判断是否需要重新评测。不要据此补齐预测。

## 结论应如何形成

选择、预测及解释要引用当前可见证据，区分直接观察、计算结果、通用知识和假设。可以使用学过的通用科研知识，但不能把记忆中的本题具体实验终点或材料完整结果当作当前数据证据；若意识到自己已知道具体目标，需披露来源和潜在污染。

不要求模型忘掉训练知识，也无法凭这一规则证明训练数据没有包含本题。数字恰好正确不单独构成违规证据。资料使用合规与科学分数分别记录，由组织者审查访问轨迹，不用报告中的某个关键词机械判违规。

## 环境要求

只使用组织者提供的 agent_release 单题目录创建干净的解题环境，不挂载完整作者包。本地软件依赖可在镜像构建阶段预装；解题阶段必须禁用网络和外部搜索工具。公开数据应只读，/workspace/results 单独可写。具体隔离必须由运行平台落实，配置文件和本规则本身不是已经生效的证明。
