# Input data

1. O'Kane & Walker, University of Bath Research Data Archive, DOI: 10.15125/BATH-00251. The bootstrap retrieves selected transient-current CSV files used in the 2017 *Journal of Materials Chemistry C* paper.
2. Parion & Vermang, *Data on degradation in scalable wide-bandgap perovskite solar cells*, Zenodo DOI: 10.5281/zenodo.18423433, CC-BY-4.0. The bootstrap retrieves the 5.6 MB data archive and checks its published MD5.
3. Ion-migration transport anchor: Zhang et al., *Effect of Halide Ion Migration on the Electrical Properties of Methylammonium Lead Tri-Iodide Perovskite Solar Cells*, DOI: 10.1021/acs.jpcc.9b04662.
4. Recovery-mechanism anchor: *Bias-Dependent Dynamics of Degradation and Recovery in Perovskite Solar Cells*, DOI: 10.1021/acsaem.1c00588.

The package does not redistribute the Bath or Zenodo raw archives. They are fetched during environment build.
