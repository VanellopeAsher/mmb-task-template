# Tools

- `inspect_transients.py`: inventories the downloaded CSV files and reports columns, row counts, missing values, and numeric ranges.
- NumPy/pandas/SciPy/lmfit: time-series inspection, exponential relaxation fits, Arrhenius fits, and uncertainty analysis.
- For chemical evidence, use the source-linked TOF-SIMS/XPS literature and the supplied device degradation dataset. The task does not mandate one fitting model.
