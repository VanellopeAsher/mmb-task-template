# Input data

Primary raw dataset: Wilson et al., *Raw data - Operando X-ray Absorption Study of TiO2-Supported Au, Cu, and Au-Cu Catalysts for Butadiene Selective Hydrogenation*, Recherche Data Gouv, DOI: 10.57745/EQL6HT.

The bootstrap downloads `DataXAS.zip` and `MassSpectrometer.zip` through the Dataverse API and verifies their published MD5 values. The Agent input under `/workspace/data/raw` contains 1,579 original XAS scan exports, 1,578 normalized spectra and eight mass spectrometer exports. The source archives and author-generated MCR results are excluded from the image.
