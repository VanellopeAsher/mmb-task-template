# Input data

Primary raw dataset: Wilson et al., *Raw data - Operando X-ray Absorption Study of TiO2-Supported Au, Cu, and Au-Cu Catalysts for Butadiene Selective Hydrogenation*, Recherche Data Gouv, DOI: 10.57745/EQL6HT.

The bootstrap downloads the public `DataXAS.zip` and `MassSpectrometer.zip` archives through the repository's Dataverse API and verifies the published MD5 values. The dataset also contains ac-STEM images; these are not required for the core numerical answer and are not downloaded by default.

Licence: Etalab Open Licence 2.0 (dataset metadata reports compatibility with CC-BY 2.0). Raw data remain in the build environment and are not bundled in this ZIP.
