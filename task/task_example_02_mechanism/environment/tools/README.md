# Tools

- `inspect_xas_archive.py`: inventory extracted XAS and mass-spectrometry files, report extensions, sizes, and candidate tabular files.
- Python stack: NumPy, pandas, SciPy, scikit-learn, matplotlib. Use these for spectrum normalization, PCA/MCR-style decomposition, EXAFS fitting support, and time-aligned product analysis.
- The task does not mandate MCR-ALS or a specific fitting workflow. Cross-check structural assignments against both XANES and EXAFS evidence.
