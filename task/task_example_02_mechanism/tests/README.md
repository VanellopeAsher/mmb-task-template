# Objective verifier

The isolated verifier checks source-derived activation, reaction-XANES, cross-sample mass-channel and post-edge fingerprint evidence. It then requires a consistent comparison of competing mechanisms and one controlled experiment with different predictions under two retained rivals. A numeric-only answer receives zero. The verifier accepts two scientifically distinct experiment designs and rejects extra unscored narrative fields. `reference_answer.json` is author-only calibration data and must never be copied into the Agent image. `test_adversarial.py` checks alternate valid designs, numeric failures, overclaims, missing controls, and non-finite values under ordinary and optimized Python.
