# Objective verifier

The verifier compares process claims, per-mechanism evidence states and inference limits to the independent reaction reference. It checks XANES, MS and post-edge numeric evidence with the original tolerances and verifies the direction of the Au and AuCu MS contrasts. Any invalid or incorrect scored field gives zero reward. JSON key order is immaterial. Duplicate fields and nonfinite constants are rejected. Optional follow-up text is unscored.
