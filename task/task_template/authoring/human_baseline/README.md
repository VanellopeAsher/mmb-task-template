# Human baseline

Recruit exactly five independent domain experts. Give each the same `environment/` snapshot and the per-person time limit specified in `task.toml` (normally eight hours). Record anonymized expert identifier, expertise, start/end time, environment image digest, visible materials, experiments, submitted artifacts, scientific adjudication, and protocol deviations. If one expert solves the problem, mark it human-solvable. Only five valid failures support a human-hard label. Simulated attempts may illustrate the record format, but cannot establish empirical human difficulty. Obtain permission before publishing identifiable contributions.
