# Expert reference material

This author-only directory holds evidence that the question has accessible, checkable signal. `feasibility_report.md` states the evidence, assumptions, budget, and unresolved limits. `reproduce.sh` checks reproducible claims in that report; it need not solve the whole question. Optional `witness/` may hold a complete or partial example path. None is a unique answer key or an Agent-facing instruction. The independent verifier lives in `tests/`.
