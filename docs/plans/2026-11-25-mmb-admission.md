# MMB admission implementation

1. Audit the protocol, target and upstream. Record the pinned reuse map.
2. Add the intake store, immutable manifest commits and version-bound workflow events. Exercise ZIP validation, deduplication, access and revision impact logic.
3. Register eight teams and implement author-forwarded invitations, blind attempts and scoped escalation. Verify that direct requests for private files fail before lock.
4. Stage trusted upstream checks, ingest commit-bound execution evidence and gate technical and final approvals. Verify infrastructure failures are distinct from numerical zero.
5. Connect the workflow to a single actionable Portal, use real local source packages to test intake, then exercise representative workflows in a simulation data store.
6. Run the integration suite and document which execution evidence is available.
