Example 06 has a computed structural witness, objective numeric fields, adversarial verifier tests and a passing Harbor CI for its scoped engineering pilot. The `solution/solve.sh` scripts copy prepared answers, so each task needs a separate substantive witness before its scientific answer can be accepted. `tests/reference_answer.json` duplicates `solution/answer.json` in each proposal.

## Cross-cutting checks

- The original five-example ZIP contains only a small candidate CSV for Example 04; most other raw inputs are fetched during image build. Subsequent live source checks have verified Example 03's Zenodo archive, Example 04's isotherm/process archives, and Example 06's CIF checksums. Docker image builds are covered only where CI is noted below.
- A follow-up source check found that Example 03's six Bath download URLs used incorrect file IDs (the original `Fig4a.csv` URL returned HTTP 404). The IDs have been corrected against the Bath archive's file links; this fixes source addressing, not the missing experimental-design oracle.
- The user's revised Example 03 attachment supplied a more precise Prete source interpretation. Table 1's eight fitted-parameter rows and source observations have been added to authoring evidence and cross-checked against the accepted manuscript. An exact-match verifier from the attachment was not adopted: it accepted contradictory measurement-purpose text and rejected alternative predictions solely because they differed from a fixed answer.
- Example 03's existing Zenodo archive was downloaded and matched MD5 `0985215dfb04dbba281eb6bb46bf0a8a`. `authoring/evidence/recompute_stress_signals.py` derives a D2 post/pre 10–100 kHz capacitance ratio of 0.996 (unpaired specimens), versus 0.459 and 0.510 for paired L2 cells, and exploratory PL peak shifts of -1/-3 nm (D2) versus -21/-12 nm (L2). These observed outcomes offer a path to an empirical assay-selection verifier, but the small and uneven sample sets require a frozen QC/uncertainty protocol.
- Example 06's nine source CIF URLs returned HTTP 200 and matched the recorded Git blob SHA-1 values in a live source check.
- Example 06 now has a structural witness (`solution/witness/structure_metrics.py`): it checks periodic Zr6 connectivity, identifies complete eight-carbon linkers, and constructs cluster-linker quotient graphs. The three primitive-cell sources are now repeated 3x3x3, removing cell size as a distribution-label shortcut; reference counts and folded motif signatures were recomputed. All nine structures passed defect-family/fraction checks; the three named topologies have distinct graph signatures. `answer.json` and the verifier now also score measured fractions, complete-linker counts, and cluster degree statistics for every sample. Full periodic-net equivalence and quantitative spatial-correlation classification remain to be checked.
- Example 04's published PrISMa isotherm and process archives passed their MD5 checks. `authoring/evidence/recompute_kpis.py` independently reconstructs all four process KPIs for 642 converged equimolar simulations and excludes 10 nonconverged cases. The 298 K pure isotherms do not uniformly cover the low-pressure regime and lack full higher-temperature coverage; selecting sufficient Agent-visible inputs and a validated process computation remains open.
- Example 06's GitHub Actions run 43140857090 passed the scientific-image witness, adversarial verifier tests, Harbor lint and Harbor oracle run (reward 1.0). This establishes the current scoped engineering-pilot execution; the licence and full spatial/topological interpretation gates above still apply.
- `environment/tools/` provides small Python inspection scripts and documentation. `environment/skills/` contains README files only. These are not the broad, usable software and sourced, established Agent Skills required for a research-grade MMB environment.
- No real five-expert baseline or independent Agent trial is present. The configured rule now matches the common template: human-hard means all five experts fail within the task's time limit.
- `tests/test.sh` previously fell back to `solution/answer.json` when an Agent answer was absent. That fallback has been removed; a missing submission now receives zero reward through `verify.py`.
- The proposal verifiers use Python `assert`, which can be disabled with `python -O`; they also accept transcribed or directly selected answers. They must be replaced before live evaluation. `analysis` is ignored by reward, as intended.
- Docker is unavailable on this Windows host. Example 06's GitHub Actions run verified the Docker image and Harbor oracle/verifier execution; other examples still need the same CI evidence. A passing package/schema check alone cannot satisfy the scientific gate.

## Release gate

For each example, freeze the actual input snapshot and licence, produce `solution/answer.json` by a traceable computation or experiment, derive verifier targets from independently checked evidence, specify units and tolerances, show positive/negative/boundary tests, run the Agent and verifier images through Harbor, and document the five-expert baseline. Keep `solution/`, `tests/` and `authoring/` isolated from Agent access. Until then, these folders are authoring proposals and should not enter a benchmark reward pool.
